# Compatibilidad con enlaces antiguos de FORJA

El código del juego está en `games/forja/`.

Esta carpeta conserva únicamente la entrada antigua del catálogo ya desplegado y la portada publicada anteriormente. `index.html` redirige a FORJA manteniendo el canal de LenguArcade y los demás parámetros. El gameId y las claves de guardado siguen siendo `lexoma` para no perder progreso existente.
